## Websrc - Web parsing CLI tool.
- A Windows CLI tool to parse webpages and PDFs into clean text, Markdown, or XML.
- Features optional hierarchy-aware layout prediction - useful for archiving, scraping, and LLM/MCP context.
- Dump locally or stream to stdout. Standalone tool, written in Golang.
